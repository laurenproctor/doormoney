The install

One line, on any site

Every act on Door Money gets their own snippet. It goes wherever the site builder allows custom code: a page, a sidebar, a footer. Nothing else to configure.

<script src="https://doormoney.co/embed.js" data-act="gutter-hymns"></script>
1
The act copies their snippet

It appears on the act's Door Money dashboard the moment their board is live. Same snippet for every page it goes on.

2
The act pastes it into their site

Squarespace, WordPress, Wix, Webflow, Carrd, Shopify, a hand-built site. Anywhere that takes an embed block or custom HTML.

3
The widget keeps itself current

When the run changes, the totals change, or a new board opens, the widget updates on its own. The act never touches the code again.

The money

Why the artist's site never handles a card

The widget takes payment on the artist's page without the artist's site ever seeing the card. Here is how the layers sit.

  • The artist's site only holds one line of code. The widget itself lives on Door Money and loads into a frame the site cannot see into.
  • Inside that frame, the card field comes from the payment processor. The card number never reaches the artist's site and never reaches Door Money's servers. Only a token does.
  • Door Money holds every payment and releases it to the act weekly, exactly as it does for placements bought on Door Money itself.
  • If an artist's site is ever hacked or defaced, the widget stays untouched, because none of it is stored there.
  • Refunds, receipts and disputes run through Door Money, so the act never fields a payment question.
